## 应用工作流与 A–E 验收

此模式使用真实 `CADV2Service`、持久化版本、独立受限子进程和真实内核。A 使用用户指定的中文需求进入确定性解析器，B 使用中文修改要求；D 使用明确 IR，因此 **D 不作为复杂自然语言理解成功记录**。这里仍不包含 HTTP、浏览器或付费模型。

| 流程 | 实际状态 | 修复次数 | 应用端到端秒数 |
|---|---|---:|---:|
| A_explicit_chinese_prompt | completed | 0 | 3.819 |
| B_natural_language_hole_edit | completed | 0 | 3.510 |
| invalid_edit_rejected | failed | 0 | 0.003 |
| restore_first_revision | completed | 0 | 3.387 |
| C_real_selection_failure_recovery | completed | 1 | 6.617 |
| D_two_face_L_bracket_from_IR | completed | 0 | 3.231 |

- A：80×50×8 mm 板、四个 Ø6 通孔；孔中心 `(10,10)`、`(70,10)`、`(10,40)`、`(70,40)`，中心距 60×30 mm。实测体积 31095.22131576613 mm³。
- B：仅将孔径参数 6 改为 8，特征列表与设计约束不变，生成新 revision。实测体积 30391.504561362017 mm³；旧版本 STEP 和 GLB 仍可按旧 revision 读取。
- 非法编辑：负孔径被拒绝，最后有效版本保持不变；此预期失败不混入有效编辑成功率。
- 恢复：恢复首版 IR 并重新构建为新 revision，验证恢复后的 Ø6 几何。
- C：真实语义边选择以 0.000001 mm 容差得到 0 条边，返回 `InvalidTopologyError`。唯一局部补丁把选择容差提高到 0.00008 mm，保持 R1 与 40×30×8 主体尺寸；第二次执行、完整几何验证和 STEP 验证通过，修复记录保留原错误和补丁。
- D：60×40×6 底板加 60×6×40 立板，两个安装面各两孔，顶边 R2；包围盒 60×40×46 mm，体积 28069.911546039984 mm³。STEP 重导入后独立测得沿 X 方向、长 60 mm 的 R2 外圆柱面。
- E：每次发布的 STEP 都实际重导入；验收进一步检查真实孔径、孔位置、孔轴向深度和外轮廓，不能以文件存在代替通过。

应用流程预期结果 **6/6**。有效参数编辑成功率 **1/1**，分母为本次有效修改请求；恢复另计 1/1。修复恢复率 **1/1**，分母为刻意构造且首次真实失败的可修复任务，成功首次执行不进入该分母。如此小的样本不能推断普遍编辑或修复成功率。30 个几何 fixture 没有调用修复，其 edit/repair 指标为 `0/0 = null`，绝非 100%。

## 基准发现与修复

固定语料先发现 Polyline 的列表坐标被建模 API 错误展开，导致三角草图、旋转及加强筋失败；将坐标转换为明确点后，继续发现非 XY 草图原点错误地采用局部而非世界坐标。修复世界坐标变换后，加强筋的包围盒、实体数量和解析体积全部符合原始要求。

强化孔数验证后，又发现圆柱盲槽被误算为额外通孔；通过实体与孔腔的实际布尔检测区分贯通类别，保留额外真实通孔应失败的负面测试。所有修复修改实现或验证器，没有放宽语料中的尺寸公差、改设计尺寸或移除用户要求的特征。

本次原仓库仅支持 2D DXF，没有可比较的三维 B-Rep/STEP/版本编辑基线。因此旧版三维成功率与相对提升幅度均为 **不可计算**。首次 V2 26/30 是开发中间结果，不能冒称旧版基线。

## 复现

在已按迁移指南安装 CAD V2 依赖的 Python 环境中：

```bash
cd backend
python -m benchmarks.cad_v2.run --output /tmp/agent-cad-v2-benchmark
python -m benchmarks.cad_v2.workflows --output /tmp/agent-cad-v2-workflows
python -m pytest tests/cad_v2/test_acceptance.py -q
```

`run` 在执行前写入 `frozen-corpus.json`；逐个任务保存 IR、STEP/STL/GLB 和结果 JSON。退出码非零表示存在完整失败。`--case 29_pattern_cut_flange` 可独立复现案例，`--report-copy` 仅复制 JSON，不把大型临时 CAD 文件写入仓库。

## 边界与下一步

上述 30 项结果验证固定设计和有限语法的安装板流程，不是 30 条提示词经在线模型生成的评测。下方在线记录独立统计，不能合并成一个整体成功率。浏览器查看、视角和参数面板验收见最终交付报告的独立 UI 记录。

后续优先增加：独立人工编写的自然语言留出集、在线模型结果与解析约束交叉核验、更广的连续特征编辑、复杂曲面/装配，以及重复运行和资源压力测试。观察到应用流程约 3–4 秒、进程内几何任务通常低于 0.5 秒，进程冷启动及其周边开销值得单独剖析；优化时必须保留资源预算、取消和隔离边界。
