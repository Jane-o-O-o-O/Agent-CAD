# Agent-CAD

GitHub: <https://github.com/Jane-o-O-o-O/Agent-CAD>

Agent-CAD is an AI agent system for CAD engineering workflows, with parametric 3D modeling, 2D DXF drawings, geometry validation, and engineering file export. FastAPI, AgentScope, and Vue provide privately deployable sessions, sandboxes, tools, and real-time events.

## Core Features

 * **CAD Workbench:** Parametric parts and assemblies, 3D viewing, parameter and feature edits, and revision management.
 * **Validation and Export:** Geometry measurement, collision checks, and STEP, STL, GLB, DXF, SVG, and other exports.
 * **Tools:** Shell, Browser, File, Web Search, and external MCP integrations.
 * **Claw:** Integrated [OpenClaw](https://github.com/anthropics/openclaw) assistant with per-user containers, automatic expiry, and chat history.
 * **Task Sessions:** MongoDB and Redis manage session history and background tasks.
 * **Interaction:** File uploads and downloads, task interruption, Chinese and English interfaces, and user authentication.
